# 🌍 Language Learning AI Tutor

An AI-powered web application that helps users learn languages through grammar correction, translations, language explanations, and interactive conversations.

Built with Next.js, TypeScript, Tailwind CSS, and OpenRouter AI.

---

## ✨ Features

- 📝 Grammar correction
- 🌐 Multi-language support
- 📖 Translation assistance
- 💡 Vocabulary explanations
- ❓ Language learning Q&A
- 🤖 AI-powered tutoring
- 💬 ChatGPT-like conversation interface

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/EsterEunice/language-learning-ai-tutor.git
```

### 2. Enter Project Directory

```bash
cd language-learning-ai-tutor
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a file named:

```text
.env.local
```

Add:

```env
OPENROUTER_API_KEY=your_api_key_here
```

### 5. Run Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---



## 🎯 How It Works

1. User enters a message.
2. The application sends the message to OpenRouter.
3. AI analyzes the input.
4. The response is displayed in a chat-style interface.
5. Users can ask grammar questions, translation questions, or language-learning related questions.
